# **App Name**: AI Retro Studio

## Core Features:

- Image Upload: Users can upload their images for AI-driven transformation, supporting common image formats.
- AI Photo Restoration Tool: Utilize an AI tool to intelligently repair and restore old photos by fixing cracks, scratches, and fading, ensuring a high-quality output.
- AI Colorization Tool: Bring black and white photos to life by using an AI tool to accurately and realistically colorize them.
- AI Image Upscaling Tool: Enhance image resolution and sharpen details using an AI tool to upscale photos to 4K quality.
- AI Cartoonization Tool: Transform uploaded photos into stylized illustrations or cartoon-like images with an AI tool.
- Transformed Image Display & Download: Display the processed image side-by-side (or a before/after view if applicable) and allow users to download the enhanced version.
- Transformation History: Save and display a history of user-initiated image transformations using Firestore.
- Registration and Login via Auth: Registration and login page handled but Auth

## Style Guidelines:

- Primary color: A deep, rich indigo (#24246B), conveying sophistication and technology, used for headings, primary buttons, and branding elements. It offers excellent contrast on light backgrounds.
- Background color: A very light, almost white, cool grey-blue (#F4F4F8) that provides a clean, unobtrusive canvas, maintaining coherence with the primary hue while keeping a bright, open aesthetic.
- Accent color: A vibrant, clear purple (#BD4CEB), chosen for its strong analogous contrast with the primary indigo, perfect for interactive elements, highlights, and tool identifiers to create visual interest and clear calls to action.
- Headline and body text font: 'Inter' (sans-serif) for its modern, neutral, and highly readable characteristics across various screen sizes, aligning with the app's clean and technical aesthetic.
- Clean, modern line icons (such as those from Lucide) used to visually represent tools and actions. Icons should employ the app's accent and tool-specific colors to enhance readability and visual appeal.
- A responsive, two-column layout that effectively organizes tools and the canvas. Utilizes generous padding and margins, and presents content within distinct, shadow-enabled, rounded cards for a premium feel.
- Subtle and functional animations, including smooth hover transitions for interactive elements, gentle loading spinners (like `animate-spin` and `animate-pulse`) for processing states, and clear fade-ins for content updates.
